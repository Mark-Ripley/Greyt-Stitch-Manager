# Greyt Stitch Manager

Needle, thread, inventory and maintenance management for multi-needle embroidery machines, by Greyt Minds Studio, LLC.

This repository hosts public Windows installers and release notes only. The application source is maintained privately. Public downloads do not make the software open source; use is subject to the end-user license agreement included in the installer.

## Release status

The first public release is being prepared. No production download is available yet.

When a stable release is published, download the `Greyt-Stitch-Manager-Setup-X.Y.Z.exe` installer from [Releases](https://github.com/Mark-Ripley/Greyt-Stitch-Manager/releases). Windows x64 is required.

## Installation and updates

1. Download an official setup executable from Releases.
2. Run the installer and follow the prompts.
3. After installing an update-enabled version, the app checks for stable releases at startup and periodically.
4. Use Help > Check for Updates to check manually. Updates require permission before download and before restarting to install.

Existing versions without update support require a manual installation of the first update-enabled release. Back up your data using File > Back Up Now before upgrading.

## Version tracking

Release tags use `vMAJOR.MINOR.PATCH`, such as `v2.1.0`. Minor releases add compatible features; patch releases fix bugs; major releases introduce breaking changes. Each release includes customer-facing notes.

## Data and support

Business data is stored on your computer. Optional network sharing allows devices on your local network to access the running app. Update checks contact GitHub and its download hosts, but do not send your stitch database or license key.

Support and purchase details will be provided before public launch. Do not post license keys, customer records or private business data in public issues.
